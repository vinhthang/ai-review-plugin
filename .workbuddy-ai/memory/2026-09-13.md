**Key findings** (all reproduced by executing the real hook scripts, not just read):

- **P0**: `common.is_subagent()` claims subagent tokens first-come-first-served across conversations, but `inject-rules.py` embeds the token into the `invoke_subagent` args, which the *parent's* transcript records. Result: the parent claims its own child's token → parent classified as subagent (all shell/code restrictions lifted, full guard bypass), real child classified as primary (all writes/commands denied → bricked), Stop guard short-circuited. Sticky for 48 h. Fix direction: refuse to claim when `conv_id == parent_conv_id`; stop writing the credential into the parent transcript.
- **P1**: 15 bare-`pass` except handlers across 5 scripts + 3 fail-open `emit(allow)` handlers; the repo's own `test_ast_no_error_suppression` FAILS (39 passed / 1 failed) and aborts on the first violation. `rules/no-error-suppression.md` is referenced by `AGENTS.md` but does not exist.
- **P1**: `is_subagent()` reads only the first 8192 bytes of the transcript — token at offset 9000 is missed.
- **P1**: `payload_validator` has two divergent implementations; `jsonschema` is not a declared dependency, so the lax builtin path runs (invalid `failure_kind` enum and coordinator children missing required fields both pass).
- **P1**: `command_validator` is wired into no hook and is bypassable — `python3 -c`, `python3 -m`, `rsync ... host:/tmp/`, `rm -rf .` all ALLOWED.
- **P1**: `deploy_plugin.py` is non-atomic, no rollback, keeps stale files, and `verify_source_bundle` accepts a `hooks.json` pointing at a nonexistent script.
- **P1**: `schemas/`, `command_validator.py`, `deploy_plugin.py`, `payload_validator.py`, `test_dalio_conformance.py` are **untracked** — a clone does not contain the new subsystem.
- **P1**: README documents 3 hooks (there are 4) and claims Python 3.6+ (`dirs_exist_ok` needs 3.8+).
- **P1**: `command_validator.py` hardcodes `/Users/thanghoang/...` in 3 places.
- P2s: 50.5 ms/tool-call transcript reparse; unindexed prune on every `Ledger()`; `event_id` collisions silently drop repeated denials; FSM replay has no ordering tiebreaker; `LIKE` prefix uses `_` as a wildcard.
